## Decisions made with the user

| Date | Decision |
|---|---|
| 2026-11-04 | Repository is `https://github.com/sps1590/office-management-system` (user created it empty; we push to it). |
| 2026-11-04 | Database and Vercel project are to be created automatically rather than by hand — done by driving `neonctl` and `vercel` CLIs, each needing one browser sign-in click from the user. |
| 2026-11-04 | Stack mirrors the user's existing, proven farm-manager stack: Next.js 16 App Router, Neon Postgres over the serverless HTTP driver, Server Actions, own cookie session auth with bcrypt, Tailwind v4 design tokens. No ORM, no auth library. |
| 2026-11-04 | UUID primary keys, because the SRS schema (section 4) specifies them. |
| 2026-11-04 | Charts are hand-written inline SVG and maps use `leaflet` with a thin own wrapper — no chart library, no `react-leaflet`, no map API key. Keeps the bundle small, which the user asked for explicitly ("most optimized way"). |
| 2026-11-04 | The SRS requirement for *silent background GPS on an MDM-deployed native app* cannot be met by a web app. We build the complete server side (ingest API, device tokens, geofencing, route reconstruction, proof-of-presence) plus a foreground PWA tracker, and specify the native client separately in `docs/MOBILE.md`. Flagged to the user up front. |

## Known gaps and risks

- **Native mobile app** is specified but not built — see
  [docs/MOBILE.md](docs/MOBILE.md). The PWA tracker only reports while the
  page is open and the screen is on.
- **Email/SMS delivery** is not wired. Notification rows are written to the
  database and shown in the in-app notification centre; sending needs a
  provider key.
- **Subscription billing** is modelled (plans, tenant subscriptions) but no
  payment gateway is connected.
